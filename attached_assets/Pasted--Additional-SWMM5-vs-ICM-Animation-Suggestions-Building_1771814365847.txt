### 🎬 1: Newton-Raphson vs Successive Relaxation Convergence

```

━━━━━━━━━━━━━━━━━━━━━

Show the SAME timestep being solved by both methods:

SWMM5 SUCCESSIVE RELAXATION:
Iteration 1: Q = 10.0 ──→ H = 5.2
Iteration 2: Q = 8.4  ──→ H = 4.8
Iteration 3: Q = 9.1  ──→ H = 5.0
Iteration 4: Q = 8.8  ──→ H = 4.9  ← converging slowly
Iteration 5: Q = 8.9  ──→ H = 4.95
Iteration 6: Q = 8.9  ──→ H = 4.95 ✓ converged

   Q │     
     │ ○

     │   ○

     │

      1  2  3  4  5  6

ICM NEWTON-RAPHSON:
Iteration 1: Q = 10.0, ∂Q/∂H = -3.2 → correction
Iteration 2: Q = 8.7  ──→ H = 4.92
Iteration 3: Q = 8.9  ──→ H = 4.95 ✓ converged

   Q │     
     │ ○                     
   10├─────────────────────── 
     │                       
   9 ├───○──○ ← quadratic convergence
     │                       
   8 ├

      1  2  3

INTERACTIVE:
[Slider: Problem Nonlinearity]
  Linear ←─────────────→ Highly Nonlinear
  
  At low nonlinearity: Both converge in 2-3 iterations
  At high nonlinearity: SWMM5 needs 8-10, ICM needs 3-4
  At extreme: SWMM5 may not converge, ICM still does

WHY ICM IS FASTER PER STEP (but does more work per iteration):
  SWMM5: Simple update, many iterations
  ICM:   Jacobian matrix solve, few iterations
  
  Trade-off: ICM iterations are more expensive

```

**Why this matters:** Engineers always ask "which solver is faster?" This animation shows it is not about speed — it is about convergence behavior. ICM converges quadratically (Newton-Raphson) while SWMM5 converges linearly (relaxation). The difference matters most in highly nonlinear conditions (surcharge transitions, pump cycling, rapid changes).

### 🎬 2: Theta (θ) Weighting Factor — ICM's Secret Weapon

```
PREISSMANN THETA ANIMATION
━━━━━━━━━━━━━━━━━━━━━━━━━━

ICM uses θ ≈ 0.65 in its 4-point scheme.
What does this actually MEAN?

TIME WEIGHTING:
                    
  t+Δt ──○──────────○──── future (unknown)
         │╲         │
         │  ╲ θ=0.65│     65% weight on future
         │    ╲     │     35% weight on present
         │      ╲   │
  t    ──○────────╲─○──── present (known)
         │          │
       x=0        x=Δx

  θ = 0.5: Crank-Nicolson (centered, 2nd order accurate)
           Most accurate BUT can oscillate
           
  θ = 1.0: Fully implicit (backward Euler)
           Most stable BUT most diffusive
           Like SWMM5's approach
           
  θ = 0.65: ICM's sweet spot
            Good accuracy + good stability
            Slightly diffusive (smooths wiggles)

ANIMATION:
[Slider: θ from 0.5 to 1.0]

Show same sharp wave propagating through pipe:

θ = 0.5:  ╱╲    Sharp peak preserved
          │  │   BUT oscillations behind wave
          │  │ ~~~~ wiggles
          
θ = 0.65: ╱╲    Peak slightly rounded
          │ ╲   No oscillations ✓
          │  ╲  Best compromise
          
θ = 1.0:  ╱──╲  Peak very rounded
         ╱    ╲  Maximum numerical diffusion
         Very smooth but peak attenuated

SWMM5 COMPARISON:
SWMM5 uses backward Euler (effectively θ = 1.0)
This is WHY SWMM5 tends to smooth out sharp peaks
more than ICM does — it is more diffusive by design
```

**Why this matters:** This explains a mystery that every modeler who has compared SWMM5 and ICM results has noticed — ICM peaks are slightly sharper. It is not a bug. It is the theta parameter.

### 🎬 6: Inertial Damping — The Three Modes

```
INERTIAL DAMPING ANIMATION
━━━━━━━━━━━━━━━━━━━━━━━━━━

The momentum equation:
∂Q/∂t + ∂(Q²/A)/∂x + gA∂H/∂x + gASf = 0
  ↑         ↑              ↑         ↑
  Local   Convective    Pressure   Friction
  accel   acceleration  gradient    slope

SWMM5 applies damping factor σ to acceleration terms:

σ × [∂Q/∂t + ∂(Q²/A)/∂x] + gA∂H/∂x + gASf = 0

DAMPING = NONE (σ = 1.0 always):
┌────────────────────────────────────────┐
│ Full momentum equation everywhere      │
│ Most physically accurate               │
│ BUT: Can be unstable at supercritical  │
│      transitions and hydraulic jumps   │
│                                         │
│ ═══════╗                               │
│        ║ ← Hydraulic jump              │
│ ═══════╝   OSCILLATES wildly           │
│ ╱╲╱╲╱╲╱╲╱╲ ← numerical instability    │
└────────────────────────────────────────┘

DAMPING = PARTIAL (σ varies with Froude number):
┌────────────────────────────────────────┐
│ σ = 1.0 when Fr < 0.5 (full momentum) │
│ σ → 0.0 as Fr → Fr_limit              │
│                                         │
│ σ = 1 - (Fr - 0.5)² / (Fr_limit-0.5)² │
│                                         │
│ ═══════╗                               │
│        ╠══ ← Smooth transition          │
│ ═══════╝   Damped at jump              │
│ ──────── ← stable but less accurate    │
│                                         │
│ DEFAULT SETTING — recommended for most  │
└────────────────────────────────────────┘

DAMPING = FULL (σ = 0.0 always):
┌────────────────────────────────────────┐
│ Removes ALL inertial terms             │
│ Equation becomes diffusion wave:       │
│ gA∂H/∂x + gASf = 0                    │
│                                         │
│ ═════════════════                       │
│ ← Very smooth, very stable             │
│   But cannot model supercritical flow   │
│   Cannot model hydraulic jumps          │
│   Backwater curve is diffused           │
└────────────────────────────────────────┘

ICM COMPARISON:
ICM does NOT have user-selectable inertial damping
ICM handles supercritical transitions internally
through its adaptive convergence scheme

The user does not choose. ICM decides.

INTERACTIVE:
[Slider: Froude Number 0.2 → 2.0]
Show momentum terms as stacked bars:
  ████ Local acceleration
  ████ Convective acceleration  } These get damped
  ████ Pressure gradient
  ████ Friction slope

As Fr increases with PARTIAL damping:
  ██   Local (shrinking)
  ██   Convective (shrinking)
  ████ Pressure gradient (unchanged)
  ████ Friction slope (unchanged)
```

### 🎬 9: Continuity Error — What It Means and Why It Differs

```
CONTINUITY ERROR ANIMATION
━━━━━━━━━━━━━━━━━━━━━━━━━━

What is continuity error?

ERROR = (Volume_In - Volume_Out - ΔStorage) / Volume_In × 100%

If error = 0%: Perfect mass conservation
If error > 0: System is "creating" water (bad)
If error < 0: System is "losing" water (also bad)

SWMM5 RPT FILE:
┌──────────────────────────────────────────┐

│  ──────────────────────                  │
│  Dry Weather Inflow:     0.000 MG        │

│  External Inflow:        0.000 MG        │
│  Flooding Loss:          0.123 MG  ← ⚠  │
│  Outfall Flow:           2.280 MG        │
│  Storage Change:         0.042 MG        │
│  Continuity Error:       0.201 %   ← KEY│
└──────────────────────────────────────────┘

┌──────────────────────────────────────────┐
│  Mass Balance Summary                    │

│  Continuity Error:      0.041 %    ← KEY│

### 🎬 16: Nonlinear Reservoir — The Core Runoff Model

```
NONLINEAR RESERVOIR ANIMATION
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

SWMM5 treats each subcatchment as a nonlinear reservoir:

Rain ▼▼▼▼▼▼▼▼▼
     │
     ↓
┌──────────────────────────────────────────┐
│            SUBCATCHMENT SURFACE          │
│                                          │
│  ░░░░░░░░░░░░░░ water depth (d) ░░░░░░ │
│  ▓▓▓▓▓ depression storage (ds) ▓▓▓▓▓▓ │
│  █████████████████████████████████████  │ ← Slope S
│                                          │
│  Width (W) ──────────────────────→      │
└──────────────────────────────────────────┘
                    │
                    ↓ Runoff Q
          Q = (W/n) × (d - ds)^(5/3) × S^(1/2)
          
          Only when d > ds (depth exceeds depression storage)

MASS BALANCE:
  d(d)/dt = i - e - f - Q/A
  
  Where:
  i = rainfall intensity
  e = evaporation rate
  f = infiltration rate
  Q = surface runoff
  A = subcatchment area

ANIMATION:
[Rain intensity slider: 0 → 4 in/hr]

Phase 1: Rain begins, d < ds
  Depression storage filling
  No runoff yet
  ▓▓░░░░░░ filling ─→ ▓▓▓▓▓░░░ filling

Phase 2: d = ds (depression storage full)
  Runoff begins
  Q small at first (d-ds small)
  ▓▓▓▓▓▓░░░ → ▓▓▓▓▓▓▓░░░░ → Q starting

Phase 3: Steady state
  Rain = Infiltration + Runoff + Evaporation
  d stabilizes above ds
  Q = constant

Phase 4: Rain stops
  d decreasing, Q decreasing
  Eventually d < ds, Q = 0
  Depression storage drains by evaporation + infiltration

BOTH SOLVERS USE THIS MODEL:
SWMM5: Native implementation
ICM:   SWMM Runoff Surface type replicates exactly
       (InfoWorks has additional runoff models)
```

```

  CFL: Δt ≤ Δx/(v+c)
  If Δx = 10 ft and (v+c) = 20 ft/s:
    Δt ≤ 0.5 seconds (very small!)

SWMM5 SOLUTION: Make the conduit longer (virtually)

          Δt_max = 0.5s

SWMM5 finds the shortest stable Δt
Then lengthens all conduits that violate CFL
to allow that Δt

TRADE-OFF:
  ✓ Larger Δt = faster simulation
  ✗ Artificial length = slight flow delay
  ✗ Head loss calculation slightly affected

ICM COMPARISON:
  ICM does NOT need conduit lengthening
  Because Preissmann implicit scheme
  is NOT strictly CFL-limited
  Short conduits are handled naturally

### 🎬 30: The Equations Side by Side — Full St. Venant

```
SAINT-VENANT EQUATIONS — COMPLETE COMPARISON
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

CONTINUITY (same in both):
  ∂A/∂t + ∂Q/∂x = q

  Both solvers conserve mass
  ICM does it at more points (distributed)
  SWMM5 does it at nodes only

MOMENTUM (where they diverge):

SWMM5 (simplified node-link form):
  dQ/dt = gA(H₁-H₂)/L - gASf + Q²/A terms
  
  Discretized per LINK
  H from upstream and downstream NODES only
  Friction slope from average properties
  
ICM (Preissmann 4-point form):
  θ[Q^(n+1)] + (1-θ)[Q^n] terms at each point
  
  Discretized at EVERY computational point
  H and Q at each point
  Friction slope from local properties

BOTH SOLVE:
  ∂Q/∂t + ∂(Q²/A)/∂x + gA∂H/∂x + gASf = 0
    ↑         ↑              ↑         ↑
  Local    Convective     Pressure   Friction
  accel    acceleration   gradient    slope

BUT:
  SWMM5 solves it at link level (coarse)
  ICM solves it at segment level (fine)
  
  SWMM5 uses backward Euler (θ=1.0 effective)
  ICM uses Preissmann (θ=0.65)
  
  SWMM5 uses relaxation (many simple iterations)
  ICM uses Newton-Raphson (few complex iterations)

SAME PHYSICS. DIFFERENT NUMERICAL METHODS.
BOTH VALID. BOTH APPROXIMATE.
NEITHER IS "BETTER" — THEY ARE DIFFERENT TOOLS.

INTERACTIVE:
[Highlight each term in the equation]
[Show how each solver approximates that term]
[Show the discretization stencil graphically]
```
