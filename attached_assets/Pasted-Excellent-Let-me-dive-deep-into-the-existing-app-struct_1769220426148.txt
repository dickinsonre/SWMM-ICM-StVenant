### **1. CFL Stability Calculator**
*Where it belongs:* **Temporal Dynamics** tab

**Purpose:** Let users understand why their model might be unstable.

**Interface:**
```
┌─────────────────────────────────────────────┐
│  CFL STABILITY CALCULATOR                   │
├─────────────────────────────────────────────┤
│  Conduit Length:    [____500____] ft        │
│  Flow Velocity:     [____8______] ft/s      │
│  Wave Celerity:     [____12_____] ft/s      │
│  Time Step:         [____30_____] sec       │
│                                             │
│  ┌─────────────────────────────────────┐    │
│  │  Courant Number: 1.2  ⚠️ UNSTABLE   │    │
│  │  Max Safe Δt:    25 sec             │    │
│  └─────────────────────────────────────┘    │
│                                             │
│  SWMM5: Auto-adjusts to ~25s               │
│  ICM:   Convergence-based, likely stable    │
└─────────────────────────────────────────────┘
```

**Formula displayed:**
```
Cr = (V + c) × Δt / Δx
```

**Value:** Directly answers "Why is my SWMM5 model crashing?" — one of the most common user questions.
